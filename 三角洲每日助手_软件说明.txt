三角洲每日助手 软件说明
版本：2026-08

【一、软件简介】
三角洲每日助手是一款用于查看《三角洲行动》每日游戏数据的 Windows 桌面小工具。
无需浏览器、无需登录，启动即自动抓取当日数据并缓存，断网也能查看上一次的数据。

【二、核心功能】
· 每日数据：自动抓取当日「密码 / 制造推荐 / 兑换推荐 / 指定子弹昨日最高·最低价」
· 本地缓存：抓取后写入本地缓存，断网也可查看上一次的数据
· 系统托盘：点 × 最小化到托盘（不退出），左键或双击托盘图标唤出窗口
· 全局热键：可自定义快捷键一键唤出窗口（默认 Ctrl + Alt + D）
· 主题与置顶：支持深 / 浅色主题、窗口置顶，设置自动记忆
· 单实例：重复打开只唤起已运行窗口，不重复启动

【三、安装】
1. 双击「三角洲每日助手安装包.exe」
2. 选择安装目录（默认 C:\Program Files\DeltaForceDaily）
3. 自动创建开始菜单文件夹与桌面快捷方式，并注册到系统「程序和功能」
4. 全程零配置，把安装包拷贝到其他电脑也可直接安装使用

【四、使用】
· 双击桌面或开始菜单的快捷方式启动
· 启动后自动抓取当日数据；关闭窗口默认缩到系统托盘
· 托盘图标：左键 / 双击 = 唤出窗口；右键 = 显示窗口 / 退出
· 工具栏 ⚙ 设置：修改唤出热键、切换深浅色、置顶、完全退出

【五、快捷键】
· 默认唤出热键：Ctrl + Alt + D（可在设置中修改）
· 在「密码 / 制造 / 兑换」三个项目页之间翻页：‹ › 按钮 或 方向键 / 鼠标滚轮

【六、数据说明】
· 数据来源：kkrb.net 三角洲行动一图流
· 更新时间：密码 00:00 / 子弹价格 00:05 / 制造兑换 00:15
· 本地缓存位置：%LOCALAPPDATA%\DeltaForceNative\
· 数据仅供个人查看参考，以游戏内 / 官方信息为准

【七、卸载】
三种方式任选其一：
1. 控制面板 → 程序和功能 → 三角洲每日助手 → 卸载
2. 开始菜单 → 三角洲每日助手 → 卸载三角洲每日助手
3. 双击「卸载三角洲每日助手.exe」
卸载会自动先关闭正在运行的程序，再清理程序文件、开始菜单 / 桌面快捷方式以及本地缓存数据。

【八、常见问题】
Q：双击提示 SmartScreen 保护？
A：软件未做代码签名，属正常现象。点「详细信息」→「仍要运行」即可。

Q：托盘图标右键菜单空白 / 点击无反应？
A：请先完全退出（托盘右键 → 退出）后重新启动；若仍异常，可卸载后重新安装一次。

Q：换电脑能用吗？
A：可以。直接把安装包拷到新电脑安装即可，零配置。

Q：数据不准确？
A：本工具仅作参考，请以游戏内及官方信息为准。

【九、技术信息】
· 运行环境：Windows 10 / 11 64 位
· 单文件程序，无需安装 .NET 或额外运行库
· 内置数据抓取与本地缓存逻辑，不依赖外部配置文件
